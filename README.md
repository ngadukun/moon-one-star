A tiny program that prints a single line: the funniest one-star review of the Moon, in 120 characters or fewer. A real review format — a rating, a grievance, a reason the Moon earned its single star.

The line:

> ★☆☆☆☆ Beautiful, but shows up late every month, half-dressed, and the Wi-Fi is somehow worse up there.

## Run it

```sh
python3 main.py
```

It prints the line from `line.txt` (102 characters, cap 120) after checking it is a single line within the cap.
